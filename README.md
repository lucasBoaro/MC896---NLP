# Apresentação

O presente projeto foi originado no contexto das atividades da disciplina de graduação [*Processamento de Línguas Naturais*](https://www.ic.unicamp.br/~santanch/teaching/nlp/2026-2/), oferecida no segundo semestre de 2026, na Unicamp.

O projeto extrai grafos de conhecimento de relatos de caso clínico do conjunto MultiCaRe. Na primeira entrega, o extrator usa léxicos, gatilhos, expressões regulares e regras escritos à mão. Na segunda, o mesmo extrator é usado para medir o que dá para aprender do próprio texto com n-gramas, PMI e aprendizado de máquina clássico, sem modelos de linguagem.
